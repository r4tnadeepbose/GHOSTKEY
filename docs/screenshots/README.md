# Screenshots

Place sanitized screenshots here for the README or release notes.

Rules:

- Blur or replace window titles, process names tied to real documents, bot
  tokens, chat IDs, and the data-directory path.
- Use the default 1440 × 900 window size for consistency.
- Prefer PNG; keep files under ~400 KB.

Suggested captures:

| File | View |
|------|------|
| `dashboard-idle.png` | Idle dashboard with trace tab |
| `dashboard-active.png` | Active session with populated runtime table |
| `output-tab.png` | Rendered digest |
| `settings-tab.png` | Settings view |
